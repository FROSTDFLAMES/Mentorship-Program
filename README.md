# Mentorship-Program
HackUCF Mentorship Program Fall 2026

## A 12 Week course for Linux and Windows Internals, Reverse Engineering & Vulnerability Research
Using:
Programming Languages: Python and C
Operating Systems: Linux (Ubuntu) and Windows 11 Pro x64
Applications: IDA Pro and VSCode

### Main Objective
- Develop the technical foundations necessary to understand operating system behavior
- Reverse engineer native applications, identify memory safety vulnerabilities
- Eventually conduct independent vulnerability research.
